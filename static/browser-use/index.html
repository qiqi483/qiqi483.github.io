import asyncio
from browser_use import Agent, ChatBrowserUse
from dotenv import load_dotenv

load_dotenv()

async def main():
    agent = Agent(
        task="Find the number of stars of the browser-use repo",
        llm=ChatBrowserUse(model="bu-2-0"),
    )
    history = await agent.run()
    print(history.final_result())

asyncio.run(main())

FAQ

Answers before you ask.

Should I use the hosted cloud, CLI, or Python library?
Use the hosted cloud to send tasks through the API and let Browser Use run the agent, browser and infrastructure. Use the CLI to give an existing agent like Claude Code or Codex browser access. Use the Python library to run the open-source agent in your own application with custom tools and your choice of model.
What is the best model to use?
We recommend BU2, the model optimized for browser automation, via ChatBrowserUse(model='bu-2-0'). The best choice depends on your tasks, latency and budget.
Can I use Claude, GPT or Gemini through ChatBrowserUse?
Yes. ChatBrowserUse accepts provider-prefixed model IDs such as anthropic/claude-sonnet-4-6 or google/gemini-3-pro, or you can use each provider directly through its own wrapper and key.
Do I need to write a system prompt?
No. Agent(...) supplies the Browser Use system prompt automatically. Put your task in task=, and use extend_system_message or override_system_message only when you need custom behavior.
How do I handle authentication?
For a local browser, reuse a signed-in Chrome profile with Browser.from_system_chrome(). For cloud, use profile sync to transfer cookies, or upload a full Chrome profile to a cloud profile.
Can I use this for free?
The Python library is free and MIT-licensed. Model inference and hosted browsers are billed by their providers. You can also run a local browser with a local model through Ollama.
