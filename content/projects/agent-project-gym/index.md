## 项目简介

Agent 项目练习场是一个面向 AI Agent 开发者的练手平台，把热门 Agent 开源项目（如 OpenClaw、Hermes Agent、AutoGPT 等）整理成一份可练习、可追踪进度的题库。

每个项目都按难度（入门 / 进阶 / 高级）和方向分类，并提供学习要点、复现步骤和验收标准，方便你逐个动手实践。

## 在线体验

👉 [打开 Agent 项目练习场](https://qiqi483.github.io/AI-Agent-prctice/)

## 主要功能

- 项目浏览与详情：按方向和难度筛选项目，查看学习要点与复现步骤
- 学习追踪：记录每个项目的练习进度
- 论坛交流：与其他学习者交流
- 我的 Agent：个人 Agent 管理

## 技术栈

React · TypeScript · Vite · Framer Motion
